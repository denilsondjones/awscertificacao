# awscertificacao
Repo para armazenar notas sobre estudos de serviçso aws.

Amazon Kendra: Buscas de informacoes em documentos ou base de dados especifica.
Amazon Rekogntion: Identificação visual de imagens e videos.
Amazon Bedrock: Plataforma de desenvolviemnto de IA com acesso a varios LLM.
Amazon Comprehend: Analisar texto para identifiacar sentimentos, entidades e tópicos relevantes.
Amazon Textract: Extrair texto, dados estruturados, informaçoes de formulários e tabelas.
Amazon Translate: Tradutor de textos considerando contexto para nao perder o sentido.
Amazon Trascribe: Converte automaticamente audio/video em texto.  
Amazon SageMaker: Plataforma de desenvolvimento de ML, cria,treina e implanta ML.
Amazon SageMaker Studio: Um IDE do SageMaker para gerenciar todo o ciclo de vida de um ML em uma unica interface.
Amazon SageMaker Autopilot: Recurso que automatizada (a partir de dados estruturados) o processo de criacao e treinamento de ML.
Amazon SageMaker JumpStart: Recurso que acelera o desenvolviemnto de ML tem modelos prontos e notebook pré-configurados. 
Amazon Sagemaker Hosting: Recurso para disponibilizar ML em endpoint de API, expor em https.
Amazon SageMaker Model Monitor: Monitorar o comportamento os modelso implantados.
Amazon SageMaker Pipelines: É uma ferramenta de orquestração de CI/CD para workflows de ML, não um catálogo de modelos pré-treinados.
Amazon SageMaker Feature Store: É um repositório centralizado para armazenar e reutilizar recursos (features) de dados.
Amazon Lex: Servico que permire criar chabot inteligentes e assistentes virtuais usando NLP e reconhecimento de voz.
Amazon Polly: Converte texto em audio.
AWS Glue: Extrair, Transformar e carregar dados (ETL).
Amazon Glue DataBrew: Ser qeu visuliza, limpa e transforma dados de forma interativa sem escrever codigo.
Amazon Personalize: Servico de IA para criar sistemas de recomnedacao personalizada usa ML sem preicsa dem expetise em IA.
AWS Lake Formation: Servico que permite criar, gerencair e proteger data lakes.
Amazon Redshift: Armazear, analisar grande volumes de dados.
